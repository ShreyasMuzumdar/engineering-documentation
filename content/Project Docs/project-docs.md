# 💻 Project Docs

Outside of robotics competition, I've built projects across mechanical engineering, software, computer vision, AI infrastructure, and embedded systems. These aren't assignments or tutorials. Each one started with a problem I wanted to solve or a system I wanted to understand, and ended with something that actually worked in the real world.

The projects span a wide range of domains, but they share a common thread: I built them to learn what I didn't know. A 3D printer I could have bought ready-to-use taught me more about FDM manufacturing by forcing me to fix it. A voice assistant I could have subscribed to taught me more about local inference by making me run it myself. The constraint of building it yourself is the point.
