# 🐍 Python Automations

## Overview

Python Automations is a collection of scripts I built to eliminate repetitive tasks from my daily workflow. Each script targets a specific pain point, and the collection grew organically as I identified more things worth automating.

This project sits at the intersection of almost everything else I have built. The scripting patterns developed here fed directly into the [[Project Docs/Home Automation System|Home Automation System]] automation logic, the early versions of [[Project Docs/hermes-assistant|Hermes]], and the computer vision work in [[Project Docs/auto-tracking-camera|Auto-Tracking Camera]] and [[Project Docs/hand-tracking-mouse|Hand Tracking Mouse]].

## What I Automated

Scripts in this collection cover a range of tasks including file organization and batch renaming, scheduled data fetching and reporting, web scraping for information aggregation, notification and alerting pipelines, and utility scripts that support other projects.
